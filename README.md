# Kir-STR.github.io

Личный сайт на GitHub Pages: <https://kir-str.github.io/>. Сборка — встроенный Jekyll GitHub Pages, тема `minima`, публикуется из ветки `main`.

## Устройство

- `index.md` — главная. Список инструкций строится сам: в него попадает каждая страница с `guide: true` во front matter, новые сверху (по `date`).
- `<slug>/index.md` и `<slug>/img/` — инструкция. Генерируется из заметки Obsidian, руками не править: правки делаются в заметке.
- `scripts/obsidian2pages.mjs` — конвертер заметки Obsidian в страницу сайта.

## Опубликовать или обновить инструкцию

Оригинал инструкции — заметка в Obsidian. После правки:

```bash
node scripts/obsidian2pages.mjs "<путь к заметке>.md" <slug>
git add -A && git commit -m "<что изменилось>" && git push
```

Через минуту-две страница обновится на сайте.

Скрипт:

- переводит вставки `![[картинка.png|650]]`, выноски `> [!info]`, свёрнутые выноски `> [!example]-` и ссылки `[[#Заголовок]]` в обычный Markdown;
- копирует картинки в `<slug>/img/`;
- берёт заголовок страницы из строки `# …` заметки;
- сохраняет остальные поля front matter существующей страницы (`description`, `date`).

Картинки ищутся от корня хранилища. По умолчанию это папка заметки, другой корень задаётся ключом `--vault <папка>`.

Опубликованные инструкции:

| slug | Заметка в Obsidian |
| --- | --- |
| `claudian-mimo` | `Инструкция.md` в корне хранилища |
